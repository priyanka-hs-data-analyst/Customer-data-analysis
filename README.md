Customer Data Analysis

## Project overview
This project focuses on analsing the customer data to identify shopping behaviour different demographics, product categories, age groups, and payment methods using the data provided.

## Objectives
- Clean and preprocess customer data.
- Handle missing values and inconsistent formats.
- Perform Exploratory Data Analysis (EDA).
- Identify customer trends and patterns.
- Create interactive dashboards for business reporting.

## Dataset information
Dataset: Customer Data analysis, 
Number of records: 99,458, 
Number of columns: 10

## Tools used
Python, 
Power BI, 
Excel

## Data cleaning performed
Checked for missing/null values,
Corrected data types,
Created Total Sales column,
Created Age Group categories,
Checked inconsistent values in categorical columns,
Verified quantity and price values

## Exploratory data analysis
Gender distribution,
Age group analysis,
Revenue by gender,
Revenue by age group,
Payment method distribution,
Shopping trends across malls,
Data cleaning was performed using Python, Excel

## Key insights
Female customers generated higher revenue compared to male customers,
Clothing is the most purchased category across all age groups,
Customers aged 50+ contributed the highest number of transactions and revenue,
Cash is the most preferred payment method across all demographics,
Cosmetics and Food & Beverage categories also show strong demand,
Debit card usage is significantly lower compared to cash and credit card
